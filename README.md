Project Name:
MediQueue – Tutor Booking System

Project Description: Its a collection of Tutor list for Learning, where their details informations are stored. When someone select individual Tutors they can see the details and also know about their features.
Users can easily select their demandable tutor according to tutor's experience, institute and time.Its a fullly protected site.No One can get users and tutors private information.  

🚀 Tech Stack
Framework: Next.js (App Router)
Language: JavaScript
Styling: Tailwind CSS
JWT Authentication


📦 key features of the project
-You can see the project on vercel 
- You can sort tutors by naming and session time
- You can see Tutors details with image, experience,
Institue, and also their available slots and time.
-You can easily add and book tutors
-responsive and user friendly site
